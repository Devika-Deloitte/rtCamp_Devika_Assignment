# Playwright Assignment - rtCamp

## Setup Instructions

1. Install dependencies:
```bash
npm install
```

2. Run tests:
```bash
npx playwright test
```

## Prerequisites

- Node.js (v16+ recommended)
- Internet connection
- Playwright dependencies (installed via `npm install`)

## Test Cases

- Verify sorting by name Z to A
- Verify sorting by price High to Low
- Add items to cart and verify the checkout flow
